# Sprint 7 Gün 4 — Login Formu E2E Testi

React/Vite login formu, geçici başarı sayfası ve iki Cypress senaryosu.

## Çalıştırma

```bash
npm install
npm run dev
```

Ayrı terminalde:

```bash
npm run test:e2e
```

Başarılı giriş örneği: `erdem@example.com` / `Strong1!`, ardından şartları kabul et.
Şifre en az sekiz karakter ve büyük/küçük harf, rakam, özel karakter içermelidir.
